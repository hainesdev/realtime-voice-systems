# Portfolio asset register

This register is the publication checklist for repository assets.

| Asset | Intended use | Publication status | Review requirement |
| --- | --- | --- | --- |
| AI receptionist flow diagram | README and architecture page | Planned | Confirm no host, extension, or tenant detail. |
| Call-leg topology diagram | README, case study, and demo | Planned | Use generic caller/agent labels only. |
| SIP lab flow diagram | Architecture page | Planned | Use synthetic extension labels only. |
| Synthetic event sample | Examples directory | Included | Validate no real call data or timing. |
| Transcription demo video | README and public implementation | Planned | Review every frame, audio track, caption, and metadata. |
| Sanitized test output screenshot | Case study | Optional | Crop all machine, path, account, and network details. |

## Asset approval checklist

1. Confirm that the asset is technically accurate.
2. Confirm that it contains no credentials, PII, production endpoint, or
   internal topology detail.
3. Confirm that its claim is supported by the associated project evidence.
4. Add meaningful alt text or an accessible transcript.
5. Record the artifact's review date before publication.
