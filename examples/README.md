# Synthetic examples

`sanitized-call-events.json` is fictional data created solely to illustrate
the shape of labeled call-leg events. It is not a recording, transcript, or
redaction of a real conversation.

The sample shows why call-leg labels are valuable: downstream systems can
render, review, or store a transcript with a stable source label established
by the media topology.

## SIP/Realtime lab

The [SIP/Realtime lab](sip-realtime-lab/) contains controlled buyer-persona and
interview-practice examples. Both require a private test PBX, dedicated test
extensions, and an OpenAI API key; their local configuration and call logs are
ignored by Git.
