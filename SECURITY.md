# Security policy

This repository is a documentation and portfolio project. It does not host a
running service, PBX endpoint, or public telephony interface.

If you identify a security issue in repository content, such as an exposed
credential, personally identifiable information, or sensitive operational
detail, please do not open a public issue. Contact Daniel Haines privately
through the contact information in the repository README.

Reports should include the file path, a concise description, and enough detail
to reproduce the concern without repeating sensitive material unnecessarily.
